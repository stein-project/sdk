# Stein SDK 0.2.6: server rules

The API of the Loader library 0.1.28 (`"loader": "0.1.28"`).

- **Server rules**: `Server.allows("minimap")` says whether the server the player is on allows a feature, and `Server.restrictedBy` names the server that does not. The rules come from the signed Stein registry and only apply while playing on that server. The official mods use `minimap`, `targetInfo`, `playerDistance`, `chatMacros` and `liveReplay`.
- **A clone of this repository alone** now packs the 0.1.28 API too.
