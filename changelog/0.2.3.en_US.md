# Stein SDK 0.2.3: drawing in the world, meshes and blend modes

The API of the Loader library 0.1.24 (`"loader": "0.1.24"`). Everything new is still experimental.

- **Open source**: the code of the SDK, the template and the examples is now public, under MIT: [Stein-Project/sdk](https://github.com/Stein-Project/sdk).
- **Drawing in the world**: `WorldRender`, from `onRenderWorld`, in world coordinates and sizes in blocks — block, entity and box outlines, boxes, quads, triangles, circles, rings, beams, labels and images that face the camera, `throughWalls` for markers that must never hide, and `push`/`rotate`/`scale` for a local space.
- **Meshes**: `Mesh`, geometry built once and drawn many times, in 2D (`Render.mesh`) or 3D (`WorldRender.mesh`).
- **More 2D drawing**: `Render.line`, `polyline`, `rectOutline`, `gradient`, `arc`, `blend` with the `Blend` modes (normal, additive, multiply, screen) and `Render.Texture.smooth`.
- **Since 0.2.2**: `Server.latency`, `Inventory.resync`, `Render.playerSkin`, `Hud.setHidden`, `Keys.click`, option checks (`Option.withCheck`) and mouse buttons in key pickers.
- **Draw through the API**: the Stein renderer runs in an OpenGL core context, where direct OpenGL, `GlStateManager` and `Tessellator` calls are not supported. The template and the example now draw with `WorldRender`.
- **Build**: field references now name the class that declares the field, so a game class with an unrelated field of the same name (BlockPos and Vec3i) cannot capture it; the template zip keeps `gradlew` executable.
