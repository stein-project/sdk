# Stein SDK 0.2.0: mods com Gradle, e uma API bem maior

Os mods agora se montam com Gradle: `./gradlew build` no modelo dá o `.steinmod`, e o IntelliJ importa o projeto pronto. A linha de comando continua funcionando.

- **Plugin do Gradle** `dev.xavier.stein.mod` (ramo Maven deste repositório): `build`, `installMod` e `steinSetup`; o SDK e o JDK 25 são baixados sozinhos.
- **A API no Maven**: `dev.xavier.stein:stein-api`, com as fontes. Comandos `classpath` e `pack` para outras ferramentas de build.
- **API nova, ainda experimental** (Stein Loader 0.1.23, `"loader": "0.1.16"`):
  - contexto do mod: `ModContext`, `ModConfig`, `Log`, `Secrets`, `Lang`;
  - quem é quem entre mods: `Relations`, `Players`;
  - desenho 2D sem OpenGL: `Render`;
  - jogo e mundo: `Entities`, `Stacks`, `Effects`, `Terrain`, `Inventory`, `Keys`, `Chat`, `Screens`, `Account`, `Server`;
  - mira com opções: `Targeting.raycast(Targeting.query())`, com alcance, só vivos, e blocos que o raio atravessa;
  - `Tasks` e `Http`, e os eventos `onRelationsChanged`, `onShutdown` e `onDisconnected`.
- **Exemplos mais simples**: o mod de exemplo só mostra coisas, e o guia deixa claro o que a maioria dos servidores não permite.
