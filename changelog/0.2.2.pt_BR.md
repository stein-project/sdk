# Stein SDK 0.2.2: teclas, inventário e efeitos

A API do Stein Loader 0.1.26 (`"loader": "0.1.19"`). Tudo o que é novo ainda é experimental.

- **Teclas**: `Keys.Binding.setKey` e `Option.withKey`, que põe a tecla na linha da opção no Painel.
- **Opções condicionais**: `Option.visibleWhen`.
- **Inventário**: `useHeldItem`, `isUsingItem`, container virtual (`openVirtualNext`), `closeContainer`, `containerSize`.
- **Itens**: `Stacks.isEnchanted`, `enchantLevel`, `potionEffects`, `isSplashPotion`.
