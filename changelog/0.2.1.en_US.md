# Stein SDK 0.2.1: the Stein look for mods

The API of Stein Loader 0.1.25 (`"loader": "0.1.18"`). Everything new is still experimental.

- **Stein fonts and colors**: `Render.text` with `Typeface` (title, text, italic, mono), `textWidth`, `textHeight` and the theme colors in `Theme`.
- **Standard background**: `Render.surface` draws the same rounded background as the HUD grid. A HUD element chooses the transparency it starts with (`HudElement.defaultBackground`) or that it takes no background (`hasBackground`); the Loader draws the background.
- **HUD grid**: `Hud.cover` hides the elements underneath one of the mod's screens (like the Tab list), and `Render.gameFont` draws a block in the game font.
