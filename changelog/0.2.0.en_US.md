# Stein SDK 0.2.0: mods with Gradle, and a much bigger API

Mods now build with Gradle: `./gradlew build` in the template gives the `.steinmod`, and IntelliJ imports the project ready to go. The command line still works.

- **Gradle plugin** `dev.xavier.stein.mod` (Maven branch of this repository): `build`, `installMod` and `steinSetup`; the SDK and JDK 25 are downloaded by themselves.
- **The API on Maven**: `dev.xavier.stein:stein-api`, with sources. `classpath` and `pack` commands for other build tools.
- **New API, still experimental** (Stein Loader 0.1.23, `"loader": "0.1.16"`):
  - mod context: `ModContext`, `ModConfig`, `Log`, `Secrets`, `Lang`;
  - who is who between mods: `Relations`, `Players`;
  - 2D drawing without OpenGL: `Render`;
  - game and world: `Entities`, `Stacks`, `Effects`, `Terrain`, `Inventory`, `Keys`, `Chat`, `Screens`, `Account`, `Server`;
  - aiming with options: `Targeting.raycast(Targeting.query())`, with a reach, living only, and blocks the line goes through;
  - `Tasks` and `Http`, and the `onRelationsChanged`, `onShutdown` and `onDisconnected` events.
- **Simpler examples**: the example mod only shows things, and the guide says plainly what most servers do not allow.
