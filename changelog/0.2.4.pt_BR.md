# Stein SDK 0.2.4: ajustes de jogabilidade na API pública

A API da biblioteca do Loader 0.1.25 (`"loader": "0.1.25"`). Tudo o que é novo ainda é experimental.

- **Ajustes de jogabilidade**: `Gameplay` liga correr para todos os lados, sem atraso de golpe, manter a corrida no golpe e não frear no golpe. Até agora só o mod Combat chegava neles, por uma parte do Loader fora da API; agora qualquer mod chega. Servidores detectam: avise o jogador e comece com eles desligados.
