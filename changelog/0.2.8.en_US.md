# Stein SDK 0.2.8: items, sounds and potions

The API of the Loader 0.1.33 library (`"loader": "0.1.33"`).

- **Items on the ground**: `Entities.itemStack(entity)` tells which item an item entity carries; `Entities.pitch` gives where an entity looks.
- **Sounds and sprinting**: `Game.playSound(sound, pitch)` plays a game sound, and `Gameplay.stopSprinting()` stops the player's sprint.
- **Potions**: `Effects.ofPotion(stack)` lists a potion's effects with the duration of each, server custom ones included.
- **Text in the world**: `WorldRender.label` now draws with the game's font and shows up in the world.
