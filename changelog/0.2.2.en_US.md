# Stein SDK 0.2.2: keys, inventory and effects

The API of Stein Loader 0.1.26 (`"loader": "0.1.19"`). Everything new is still experimental.

- **Keys**: `Keys.Binding.setKey` and `Option.withKey`, which puts the key on the option's row in the Panel.
- **Conditional options**: `Option.visibleWhen`.
- **Inventory**: `useHeldItem`, `isUsingItem`, virtual container (`openVirtualNext`), `closeContainer`, `containerSize`.
- **Items**: `Stacks.isEnchanted`, `enchantLevel`, `potionEffects`, `isSplashPotion`.
