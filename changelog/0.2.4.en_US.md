# Stein SDK 0.2.4: gameplay switches in the public API

The API of the Loader library 0.1.25 (`"loader": "0.1.25"`). Everything new is still experimental.

- **Gameplay switches**: `Gameplay` turns on sprint in all directions, no hit delay, sprint through the hit and no hit slowdown. Until now only the Combat mod reached them, through a part of the Loader outside the API; now any mod can. Servers detect them: say so to the player and start them off.
