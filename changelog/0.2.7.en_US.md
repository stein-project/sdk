# Stein SDK 0.2.7: what a server can turn off

The API of the Loader 0.1.31 library (`"loader": "0.1.31"`).

- **Features a server can turn off**: list them in `features` in `steinmod.json` and ask `Server.allows("name")` before using each one. The server itself now decides, on the `SteinLoader` channel, instead of a list from Stein.
- **A whole mod turned off**: `onSuspend` and `onResume` are for what the Loader cannot see, such as your own threads or something your mod changed in the game. The Loader already cuts events, screen elements, the Panel and keys by itself.
- **Update notice**: with `source` in `steinmod.json`, the player's Panel says when a new version of your mod is out.
