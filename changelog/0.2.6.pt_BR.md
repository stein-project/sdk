# Stein SDK 0.2.6: regras dos servidores

A API da biblioteca do Loader 0.1.28 (`"loader": "0.1.28"`).

- **Regras dos servidores**: `Server.allows("minimap")` diz se o servidor em que o jogador está permite um recurso, e `Server.restrictedBy` diz o nome do servidor que não permite. As regras vêm do registro assinado do Stein e só valem enquanto se joga naquele servidor. Os mods oficiais usam `minimap`, `targetInfo`, `playerDistance`, `chatMacros` e `liveReplay`.
- **Um clone só deste repositório** agora também empacota a API 0.1.28.
