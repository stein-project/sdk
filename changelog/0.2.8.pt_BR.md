# Stein SDK 0.2.8: itens, sons e poções

A API da biblioteca do Loader 0.1.33 (`"loader": "0.1.33"`).

- **Itens no chão**: `Entities.itemStack(entity)` diz que item uma entidade de item carrega; `Entities.pitch` dá para onde ela olha.
- **Sons e corrida**: `Game.playSound(som, tom)` toca um som do jogo, e `Gameplay.stopSprinting()` para a corrida do jogador.
- **Poções**: `Effects.ofPotion(item)` traz os efeitos de uma poção com a duração de cada um, inclusive os personalizados de servidor.
- **Textos no mundo**: `WorldRender.label` passou a desenhar com a fonte do jogo e aparece no mundo.
