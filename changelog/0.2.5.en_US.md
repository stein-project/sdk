# Stein SDK 0.2.5: a new home

The API of the Loader library 0.1.27 (`"loader": "0.1.27"`), the same as before. What changes is where the SDK lives.

- **Releases and the Maven repository in the SDK's own repository**: `stein-sdk.jar`, the template and the Gradle plugin now come from [Stein-Project/sdk](https://github.com/Stein-Project/sdk). In `settings.gradle`, read the plugin from `https://raw.githubusercontent.com/Stein-Project/sdk/maven`; it has every earlier version too.
- **Earlier projects keep working**: projects on 0.2.4 or older still read the frozen `Stein-Project/stein-sdk`, with every version already there.
