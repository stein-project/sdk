# Stein SDK 0.2.1: o visual do Stein para os mods

A API do Stein Loader 0.1.25 (`"loader": "0.1.18"`). Tudo o que é novo ainda é experimental.

- **Fontes e cores do Stein**: `Render.text` com `Typeface` (título, texto, itálico, mono), `textWidth`, `textHeight` e as cores do tema em `Theme`.
- **Fundo padrão**: `Render.surface` desenha o mesmo fundo arredondado da grade do HUD. Um elemento do HUD escolhe com que transparência nasce (`HudElement.defaultBackground`) ou se não aceita fundo (`hasBackground`); quem desenha o fundo é o Loader.
- **Grade do HUD**: `Hud.cover` esconde os elementos que ficam embaixo de uma tela do mod (como a lista do Tab), e `Render.gameFont` desenha um bloco na fonte do jogo.
