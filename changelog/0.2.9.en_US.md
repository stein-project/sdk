# Stein SDK 0.2.9: sprint state and entity tints

The API of the Loader 0.1.35 library (`"loader": "0.1.35"`).

- **Movement state**: `Entities.isSprinting`, `isSneaking`, `isRiding` and `isFlying` tell what any entity is doing.
- **Double-tap sprint**: `Gameplay.setDoubleTapSprint(false)` turns off the game's sprint by double-tapping forward, until it is turned back on.
- **Entity tints**: `SteinMod.onEntityColor(entity, color)` tints a living entity this frame like the game's damage red, on the body and the armor, as strong as the color's alpha.
- **Runner icon**: `Page.icon("run")` for a Panel page.
