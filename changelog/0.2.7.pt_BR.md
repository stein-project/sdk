# Stein SDK 0.2.7: o que o servidor pode desligar

A API da biblioteca do Loader 0.1.31 (`"loader": "0.1.31"`).

- **Recursos que o servidor pode desligar**: declare a lista em `features` no `steinmod.json` e pergunte `Server.allows("nome")` antes de usar cada um. Quem decide agora é o próprio servidor, pelo canal `SteinLoader`, e não mais uma lista do Stein.
- **Mod inteiro desligado**: `onSuspend` e `onResume` servem para o que o Loader não enxerga, como threads suas ou algo que o mod mudou no jogo. Eventos, elementos da tela, Painel e teclas o Loader já corta sozinho.
- **Aviso de atualização**: com `source` no `steinmod.json`, o Painel do jogador avisa quando sai uma versão nova do seu mod.
