# Stein SDK 0.2.5: um lugar novo

A API da biblioteca do Loader 0.1.27 (`"loader": "0.1.27"`), a mesma de antes. O que muda é onde o SDK fica.

- **Releases e o repositório Maven no repositório do próprio SDK**: o `stein-sdk.jar`, o modelo e o plugin do Gradle agora vêm de [Stein-Project/sdk](https://github.com/Stein-Project/sdk). No `settings.gradle`, leia o plugin de `https://raw.githubusercontent.com/Stein-Project/sdk/maven`; ele tem todas as versões anteriores também.
- **Projetos anteriores continuam funcionando**: projetos na 0.2.4 ou anterior seguem lendo o `Stein-Project/stein-sdk` congelado, com todas as versões que já estão lá.
